# 🎬 동영상 편집 프로그램

**다운로드한 동영상의 자막을 자동으로 제거하고, 대본에 맞게 편집하는 프로그램**

## 주요 기능

- ✂️ **자막 제거**: 비디오에서 모든 자막(소프트/하드) 자동 제거
- 📝 **자막 생성**: 사용자 대본으로 SRT 자막 자동 생성
- 🎞️ **자동 편집**: 자막 타이밍에 맞게 동영상 자동 편집 (불필요한 부분 자르기 및 재배열)
- 🎨 **자막 오버레이**: 원본 영상에 자막만 오버레이 추가 옵션
- 🖥️ **웹 UI**: Streamlit으로 만든 직관적인 인터페이스

---

## 사전 준비

### 시스템 요구사항

- **Python 3.8+**
- **FFmpeg** (자막 제거 및 비디오 처리용)
  - Ubuntu/Debian: `sudo apt-get install ffmpeg`
  - macOS: `brew install ffmpeg`
  - Windows: [ffmpeg.org](https://ffmpeg.org/download.html) 에서 다운로드

### 설치 확인

```bash
ffmpeg -version  # FFmpeg 설치 확인
python --version  # Python 버전 확인
```

---

## 설치

```bash
pip install -r requirements.txt
```

## 실행

웹 UI를 열어서 동영상을 업로드하고 편집합니다:

```bash
streamlit run app.py
```

실행하면 브라우저가 자동으로 열립니다.

### 사용 방법

**1️⃣ Step 1: 자막 제거**
- 동영상 파일 업로드
- "🗑️ 자막 제거 시작" 버튼 클릭
- 자막이 제거된 영상 미리보기

**2️⃣ Step 2: 자막 생성 & 편집**
- 대본을 텍스트로 입력 (한 줄에 하나씩)
- 자막이 자동으로 생성됨 (동영상 길이에 맞게 균등 분배)
- 생성된 자막 미리보기로 확인
- 편집 방식 선택:
  - **자막에 맞게 편집**: 각 자막 구간에 해당하는 영상만 추출해서 이어붙임
  - **자막 오버레이만 추가**: 원본 영상에 자막 텍스트만 오버레이 추가
- 편집 완료 후 다운로드

## 프로젝트 구조

```
.
├── app.py                         # 웹 UI (streamlit run app.py)
├── src/
│   ├── __init__.py
│   ├── subtitle_remover.py        # 자막 제거 (FFmpeg)
│   ├── subtitle_generator.py      # SRT 자막 생성
│   └── video_editor.py            # 비디오 편집 (자막에 맞게 컷/합치기)
├── temp/                          # 임시 파일 저장
├── output/                        # 편집된 동영상 저장
├── requirements.txt
└── README.md
```

---

## 동작 원리

```
동영상 + 기존 자막 입력
  │
  ├─▶ FFmpeg ────▶ 자막 제거된 영상
  │
  ├─▶ 사용자 대본 입력
  │
  ├─▶ SRT 생성 ──▶ 자막 타이밍 설정
  │
  └─▶ 영상 편집
        1) 각 자막 구간에 해당하는 영상 부분 추출
        2) 추출한 부분들을 순서대로 연결
        3) 편집된 영상 저장 ✅
```

또는 **자막 오버레이 옵션**으로 원본 영상에 자막 텍스트만 추가할 수도 있습니다.

---

## 주의사항

- **FFmpeg 필수**: 설치되어 있어야 자막 제거가 가능합니다.
- **처리 시간**: 긴 영상은 편집에 시간이 걸릴 수 있습니다.
- **자막 균등 분배**: 기본적으로 입력한 대본의 각 줄에 동영상 길이를 균등하게 분배합니다.
- **소프트 자막**: 현재는 소프트 자막(자막 트랙) 제거를 지원합니다.
